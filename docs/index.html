AI से 3D Explainer वीडियो बनाएं

बिना किसी महंगे सॉफ्टवेयर या सब्सक्रिप्शन के। नीचे दिया गया MCP लिंक अपने Claude या ChatGPT में जोड़ें और सिर्फ़ लिखकर 3D वीडियो तैयार करें।

Step 1 — आपका MCP Server URL
https://ai-3d-video-studio-mcp.kinetra3d.workers.dev/mcp

Step 2 — AI से कैसे जोड़ें?

1

Settings → Connectors खोलें

अपने Claude ऐप या वेबसाइट की सेटिंग्स में जाकर Connectors पर टैप करें।

2

Add custom connector दबाएं

ऊपर + बटन दबाएं, नाम में Kinetra3D लिखें और ऊपर कॉपी किया गया MCP लिंक पेस्ट करके Add कर दें।

3

नई चैट में वीडियो बनवाएं

अब बस लिखें कि आपको किस टॉपिक पर 3D वीडियो चाहिए। 90 सेकंड में आपका वीडियो लिंक तैयार हो जाएगा।

1

Settings → Apps & Connectors खोलें

ChatGPT में Developer Mode / Custom MCP Connector विकल्प खोलें।

2

MCP Server URL पेस्ट करें

नाम में Kinetra3D डालें, ऊपर दिया गया MCP URL पेस्ट करें (Authentication: None रखें) और Save करें।

3

प्रॉम्प्ट देकर वीडियो जनरेट करें

चैट में 3D सीन और वॉयसओवर की भाषा बताएं—ChatGPT खुद 3D वीडियो रेंडर कर देगा।

Step 3 — वीडियो बनवाने के सैंपल प्रॉम्प्ट

अच्छा 3D वीडियो पाने के लिए हमेशा 3 चीज़ें लिखें: (1) सीन में क्या दिखेगा, (2) कैमरा/रोशनी कैसी हो, (3) वॉयसओवर हिंदी या इंग्लिश में। नीचे से कोई भी प्रॉम्प्ट कॉपी करें:

SCIENCE EXPLAINER (ZACK D. FILMS STYLE)
Kinetra3D टूल का उपयोग करके एक 3D explainer वीडियो बनाओ जिसमें दिखाया जाए कि ब्लैक होल अपने पास आने वाले तारे की रोशनी को कैसे मोड़ता है। डार्क स्पेस लाइटिंग रखो और हिंदी में छोटा सा वॉयसओवर जोड़ो।
3D PRODUCT / OBJECT SHOWCASE
Kinetra3D टूल से एक 3D वीडियो बनाओ जिसमें एक चमकता हुआ सुनहरा क्यूब हवा में धीरे-धीरे घूम रहा हो, चारों तरफ नीली स्टूडियो लाइट हो और इंग्लिश में प्रभावशाली वॉयसओवर हो।
क्लाउड पर 3D वीडियो बन रहा है...
Blender 3D एनीमेशन और AI वॉयसओवर रेंडर होने में लगभग 60–120 सेकंड लगते हैं। तैयार होते ही वीडियो अपने आप यहीं चल जाएगा।
